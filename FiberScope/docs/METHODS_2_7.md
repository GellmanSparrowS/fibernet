# FiberScope 2.7：几何一致性与圆柱纤维制造

## 1. 节点扰动与固定拓扑

在参考构型中生成闭合单元，按铺展规律建立共享边的独立纤维身份，并为平面外边界保留配对回程。内插节点和边表建立后，对每个节点施加独立、确定性种子的均匀平面扰动。设单元尺度为 L=10、界面扰动参数为 p，则每个坐标分量的扰动服从 U(-0.35Lp,0.35Lp)。扰动作用于内插点及连接节点，而非只移动单元角点。高度数拆分在随后进行，端口随其参考节点移动。

欧拉回路由参考图边身份确定。改变位移谱或扰动参数不改变边编号、邻接关系及遍历顺序。重合纤维在图中保持不同身份；实体融合是独立的几何步骤，不将布尔后的接触关系反写为原始物理图。拓扑连续性不等价于任意参数下的工艺可制造性。

## 2. 曲面映射与跨页面一致性

曲面四边面分别承载局部单元。局部编译关闭平面外边界镜像，避免每个曲面面片再次增加双重回程。明确对应于参考四角的节点固定在网格角点，邻接面按原始角点编号共享身份。没有共同角点的单元通过确定性面边中点和配对连接段跨接。未连接部分通过参考几何建立固定连接；变形时不重新按空间距离识别邻居。

曲面页面保存完整 ManufacturingNetwork。制造线程直接接收该对象，不使用另一套参数重新编译。预览、实体中心线和路径CSV由这一对象产生。OBJ三角面及一般多边形经解析、必要减面和公共边中点细分转换为相容四边面；这不是保证任意原模型的全局高质量重拓扑。

## 3. 毫米坐标与打印方向

平面默认成品外包络100×100×2 mm，纤维直径2 mm。平面XY轴分别缩放，Z向厚度独立控制。曲面保留三轴比例，默认宽长上限200 mm、高度上限250 mm，三轴均限制在250 mm内，2 mm表示纤维直径。

对于Y-up参考OBJ，制造入口采用(x,y,z)→(x,-z,y)的刚性旋转，使竖直方向对应打印Z轴；内置金字塔使用Z-up，无需旋转。程序接口PrintSettings.up_axis可明确选择y或z。缩放时从各外包络限制中减去纤维直径，采用最小比例；最终实体最低坐标归零。视图相机变换不写入打印坐标。

## 4. 圆柱实体与交汇融合

将每条非零长度中心线段构造为16边截面的棱柱近似圆柱，并以16分段节点球近似连接转角。使用manifold3d 3.5.1对这些体积进行布尔并集，融合交汇处。共线的度二节点只在实体几何中消除，路径节点保留。精确重合中心线仅生成一次材料，但独立路径身份仍全部导出。各圆柱截面采用确定性微小相位差，避免大量完全共面交汇。并集以半径0.001倍容差简化，进行两轮0.0001 mm量化和退化面清理。对仍然几何重合但拓扑独立的零厚度接触顶点，沿各自内法向做不超过三次的微小分离（单次半径0.001倍，默认1–3微米），避免STL读取器将它们焊为非流形边；原始中心线与路径不变。验证覆盖浮点STL顶点合并后的边邻接，而不只检查内存面索引。以96个几何元件为一组计算，组间检查取消；最后一次原生布尔合并需完成后才能响应取消。

圆柱截面的最大弦误差为r[1−cos(π/16)]，r=1 mm时约0.0192 mm；该数值不是节点球或整个布尔网格的统一误差上界。平面厚度不同于直径时，Z向做仿射缩放。实体通过每条三角边恰有两个相邻面及非零有向体积检查。STL和声明毫米单位的3MF原子写出。流形检查不能替代切片、悬垂、最小特征或实物验证。

制造预览使用实际实体三角网格、深度排序和面法向着色；超过100000个三角面的预览进行减面，导出保留完整网格。节点中心线与实体使用同一相机和自动居中变换。球体/交点和减面显示可能呈现局部棱面。

## 5. 默认模型预处理与可复现性

参考原件保持只读。衣服和鞋采用最长轴112个体素的有界点云包覆、截面闭合与填洞、平滑、三角化和离线QuadriFlow规整四边化。此过程保留外轮廓，省略薄缝和内部装饰，不视为原模型的精确复刻。不得直接只保留原始模型最大连通块，否则衣服可能只留下袖片。

铁塔采用原始高度与横向包络拟合，单调平滑轮廓，生成18层、每侧8段的规整四边曲面，底部保留四个拱形开口。它是参考轮廓演示，不是建筑细节模型。金字塔边长120、高90，四侧三角面经相容细分生成108个四边面，底部开放，纤维边界位于同一平面。

复跑：`python scripts/prepare_demo27.py`。衣服/鞋按最终缓存文件续跑；外部四边化必须同时通过进程返回与输出存在性检查。QuadriFlow仅在离线资产准备中使用，不进入EXE；工具路径可在脚本中配置。参考原始资产许可未提供，其状态记录在assets/obj/reference26.json，文件名为兼容历史接口保留。

## 6. 预算、数据与扩展

网络UI可设1–128个周期、0–24个内插点，但图生成保留40000节点预算，防止组合参数导致内存失控。目标拉伸可设至20；该范围不是数值收敛保证。机器学习样本数允许10–2000，支持已有断点数据机制。学习schema升级为structure14-v4-geometry27，避免恢复旧扰动逻辑的数据缓存；仿真源哈希同步更新。

AI完整流程通过内部工具start_print_workflow或文本“准备打印”“完整流程”触发，界面不显示专用流程按钮。运行时输入“停止流程”取消。终点是实体文件与切片软件交接，不绕过打印机型号、材料和切片设置。

## 7. 验证入口

- `python scripts/run_tests.py`：全部回归。
- `python tests/selftest_geometry27.py`：全类型节点扰动、固定路径、大网格、圆柱尺寸、全部打包OBJ真实实体、250mm边界。
- `python tests/gui_geometry27.py`：文本取消、隐藏控件、曲面对象交接、方向和大网格预览。
- `python scripts/review_geometry27.py`：本地生成模型视图和金字塔STL/3MF供人工核对；不会发送打印任务。
- `python scripts/verify_print_formats25.py`：独立读取STL/3MF检查尺寸、封闭性、方向。

Bambu发现已覆盖D:/Bambu/Bambu Studio/bambu-studio.exe；金字塔及旧参考模型另用scripts/verify_bambu27.py执行本机Bambu的STL/3MF导入和再导出检查，复核网格封闭性、方向与尺寸；实际切片和实物打印不属于上述自动检查结果。
