# 统一图数据模型：Methods 草稿

## 图表示与边身份

纤维网络表示为带几何坐标的图。每个节点具有三维浮点坐标；二维网络的第三坐标为零。每条边以有序端点、半径、材料属性及可选内部点表示。不同边允许具有相同的一对端点；此时它们仍是独立的纤维实例，可分别参与路径、接触和力学统计。普通图生成接口默认合并相同无向端点的重复边；制造拓扑转换明确启用平行边保留，因此旧版简图调用的默认行为不变。

APP 的制造拓扑先在基元角点图上进行周期复制和节点识别，再补充边界镜像纤维、连接分量和偶度修正。随后按参数化形变谱在各边插入内部点，得到参考坐标、变形坐标与边表。该步骤的输出是制造网络；转换为库图时，按原节点顺序逐点插入、按原边顺序逐边插入，不合并平行边。制造路由的边编号和拓扑标识作为图元数据保留。单笔闭合路线仅表明该图满足所采用的连通与欧拉条件，不构成打印设备、材料或粘结工艺的完整可制造性认证。

## 可重复性与验证

目前的回归基准覆盖方形、六边形、圆环和笼目基元，各为 2×2 周期，分别采用 0、1、2 个每边内部点。对每个组合，比较制造网络与库图的节点数、边数、坐标数组和有序端点数组，并检查路由边编号覆盖图边范围。库图的复制、字典序列化往返，以及 NetworkX 的 `MultiGraph` 往返均检查平行边数量。库的普通加边仍进行默认去重。测试没有证明所有单元、所有周期规则和所有导出格式等价；后续需扩展到随机种子、多种变形谱、三维曲面和实体导出。

软件模型中的长度单位由输入坐标约定，图容器本身不进行长度单位转换。向实验材料参数、打印毫米尺寸或 FEM 网格传递时，应在相应模块明确写出转换规则与数值尺度。
