## 模块迁移表

| 领域 | 当前 APP 实现 | 当前库实现/接口 | 融合判据 |
| --- | --- | --- | --- |
| 结构生成 | `fslab/structure.py`, `cell_rules.py`, `cell_cycles.py` | `fibernet/gen/pattern.py`, `core/structure_graph.py` | 以 APP 的单元编辑、形变谱、周期规则为主；统一图表示、单位、种子和周期边身份；同参数输出的拓扑及坐标可复现。 |
| 力学模拟 | `fslab/engine2.py`, `simcache.py` | `fibernet/sim/`（含加速引擎） | 区分轴向弹簧、弯曲、接触与梁 FEM 的物理假设；同一模型对照解析解或可信基准；不得仅因曲线相似就宣称物理等价。 |
| 特征与接触 | `fslab/features.py`, `contact.py`, `percolation.py` | `fibernet/analysis/`, `ml/features.py` | 对齐特征定义、面积/长度单位、接触排除规则；覆盖典型交叉、共线重叠及无接触样本；控制候选对内存。 |
| 制造与导出 | `fslab/manufacturing.py`, `print_export.py`, `tube_solid.py` 等 | `fibernet/io/mesh_export.py`, `fea_export.py` | 明确几何可打印性与工艺可制造性的边界；统一实体单位、连通性、路径和导出格式验证。 |
| 机器学习/逆设计 | `fslab/learning.py`, `mlmodel.py`, `inverse.py`, `dataset_stream.py` | `fibernet/ml/`, `rl/` | 保留可断点续跑与原子保存；训练/验证按结构族、种子或批次隔离；记录数据谱系、预算和不确定性。 |
| 曲面映射/可视化 | `fslab/surface_mapping.py`, `surface3d.py`；`studio/` | `fibernet/viz/` 及 3D 工具 | 核心计算作为库 API，GUI 仅做交互；检查输入 OBJ、面片分辨率、坐标比例和导出一致性。 |

## 顺序与每阶段验收

1. **基线与隔离**：已锁定独立 APP 的 `bdcc82e` 和公开库的 `aeea216a`，并建立独立 Git 检出；下一步做可运行的功能/API 清单与最小基准数据，记录现有测试、依赖和版本差异。
2. **共享数据模型与生成**：先修复平行纤维在图转换、复制、序列化和 NetworkX 导出中的表示与往返；默认无向边去重行为须保持兼容。随后迁移 APP 的高级生成能力，让 APP 调用同一共享实现。保留旧数据加载的兼容测试。
3. **特征、仿真、制造**：按模块逐一迁移。每一模块先写方法定义及带数值容差的基准，再切换 APP；旧实现确认无其他调用后才删除。
4. **学习与运行体验**：批量任务有进度、预算、内存上限、原子检查点；库提供稳定 Python 3.10 API，APP 提供相同参数的可见回读。
5. **发布与论文证据**：跨平台安装、完整测试、用户教程、发布包冒烟、科学验证和消融。论文把软件功能、模型假设、实验观察分开，不将软件实现当作科学结论。

每阶段完成后先执行相关测试，再更新 `PROGRESS.md`、`files_registry.json` 和可直接复用的 Methods 文档。公开提交和发布须在最终审查后进行。

## 论文主线候选与证据门槛

建议围绕“可制造约束下的纤维网络设计闭环”组织，而不是软件功能清单。主线可按**生成空间与拓扑约束 → 力学/接触表征 → 目标驱动搜索 → 制造与实验验证**推进。图的最终设计依赖真实结果：每张主图只承载一个可检验结论，结构图覆盖不同拓扑；优先矢量，位图仅用于形貌、软件界面和实验图像。需预注册或至少明确：对照方法、结构族外推、种子重复、计算预算、误差与不确定性、物理/实验校验。没有数据支持的“高性能”“普适”“高精度”等措辞暂不写入结论。

中文稿及 PPT 在核心数据和图表通过校验后启动；参考文献逐句查原始英文论文，并保存 DOI、原文链接和具体支撑句，不复用一篇论文给多句不相关陈述。
