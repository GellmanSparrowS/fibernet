# 阈值招募网络删减预实验（2026-09-24）

## 目的与可复现入口

本轮只检验研究问题是否值得扩大：完整拉伸轨迹中长期未被阈值规则招募的边，在删除后重新计算时，会怎样改变模型反力？预实验不是制造优化或 AI 预测结果。运行入口为 `python benchmarks/percolation_pruning_pilot.py`，逐结构原子写入 `benchmarks/results/percolation_pruning_pilot.json`；同配置重复运行会跳过已有完整案例。代码和结果保留在本地统一检出，尚未提交或发布。

计算使用 `Engine2` 原始反力而不是缓存层的单调包络。四种 2×2 结构（方形、六边形、圆环、笼目）每边一个内部点，拉伸终点 1.4，20 个增量，每增量最多 2000 步，接触关闭、弯曲开启。阈值为逐帧最大正边应变的 5%（另有求解器默认的最小阈值和滞回规则），固定随机种子 23。每种结构删除约 10% 的**边数**，并要求剩余图连通。排序对照为完整轨迹低招募、随机、高招募；低招募使用全轨迹，属于事后选择，不能视为提前预测。

## 数值观察

表中反力为末帧原始模型反力，`Δ` 是相对于同结构原图的变化；长度百分比是实际删除的初始边长之和占总边长比例。绝对反力单位依赖当前求解器参数，不据此作实验强度声明。

| 结构 | 原图反力 | 长期未招募边数 | 低招募：删长 / 反力 Δ | 随机：删长 / 反力 Δ | 高招募：删长 / 反力 Δ |
| --- | ---: | ---: | ---: | ---: | ---: |
| 方形 | 300000 | 24 | 10.4% / 0.0% | 10.4% / −5.9% | 10.4% / −21.9% |
| 六边形 | 306947 | 16 | 9.4% / ≈0.0% | 10.2% / −15.5% | 10.5% / −50.5% |
| 圆环 | 151497 | 8 | 4.1% / −1.5% | 8.8% / −8.6% | 7.8% / −20.6% |
| 笼目 | 464755 | 48 | 9.6% / ≈0.0% | 9.4% / −8.2% | 3.4% / −6.0% |

这是小样本模型筛选信号：在这些设置下，事后低招募排序删边后的末帧反力下降较少。它**不能**证明长期未招募边没有力学作用、相同质量预算下优于其他方法，或该操作可制造。所有候选虽然保持图连通，却产生了超过两个奇度节点，因而不满足当前闭合/连续路线的简单拓扑筛查。尤其圆环和笼目案例，各对照的删除长度差异很大；笼目高招募组仅删除 3.4% 长度，与低招募组的 9.6% 不可直接比较。反力的单点读数也不能替代全程刚度、耗散/做功和失稳评估。

## 下一轮判定门槛

1. 改用**相近删除长度**而非仅相同边数，并报告预算误差。增加简单几何基线与多随机种子；在不同拉伸方向、接触设置和阈值下重算。
2. 将图连通、奇度、路线连续性、最小纤维长与交叉等制造约束纳入候选生成；可先比较成对/闭环删除与等量纤维重排。如果可行集合太小，应如实报告而不是把无约束结果写成可打印设计。
3. 保存全应变区间原始反力、正/负应变、弯曲及接触贡献；检查末帧反力上限或夹持/求解设置是否导致方形结构的 300000 平台。先通过简化解析图或梁 FEM 核对物理意义。
4. 只有上述对照稳定后，才建立早期帧预测任务。训练输入不能包含末段轨迹或事后选择标签的派生信息，测试按结构族和尺寸隔离，并用重新仿真的材料–性能结果评价。

因此，当前论文主线保留“共享科学软件平台 + 可检验的时序招募干预案例”，但不把删减有益或 AI 改善作为已成立结果。若制造约束和等预算对照削弱该现象，应调整案例结论或选择重排而非删边。
