# Explicit sample-to-node preparation

The bounded LAMMPS bead adapters reject edges with stored internal points: they do not silently flatten geometry or infer bead properties. For a deliberate geometry-only transformation, import `expand_edge_samples` from `fibernet.integrations.lammps_geometry` and call `expanded, report = expand_edge_samples(graph, edge_ids=[edge_id])`.

The returned graph is detached. Each selected edge is replaced by straight edges joining its original endpoints and stored samples in order. New IDs are allocated in the supplied edge ID order; the report maps each retired edge ID to new node and edge IDs in path order. Unselected edge IDs and original node IDs remain; new nodes are never merged by proximity. Exact sample collisions with any existing node or another promoted sample are refused, leaving ambiguous junction decisions to the caller. Stored points become explicit nodes, but the continuous path between them is approximated by straight segments. Node insertion order can change through native-record reconstruction.

This deliberately changes topology and discretization. Each new edge copies radius, material and source edge metadata and has `segments=1`; new nodes have no boundary flags or metadata. Copied metadata is not interpreted: embedded old IDs are not remapped, and cross-section orientations or local coordinate frames are not transported. It **does not** assign masses, bond coefficients, external forces, restraints, angles or units, and it does not establish mechanical equivalence. Supply those values for the new stable IDs explicitly before calling the existing LAMMPS preparation API. Unselected edges with internal points remain unchanged and will still be rejected by that API.

The helper accepts a finite native JSON-roundtrippable 3D graph, explicit unique selected edge IDs, at most 256 input samples, and at most 256 output nodes and 1024 output edges. Coordinates must be exactly representable as float64. Count and JSON bounds are not total-memory or runtime guarantees. It does not launch LAMMPS or qualify the physical model.
