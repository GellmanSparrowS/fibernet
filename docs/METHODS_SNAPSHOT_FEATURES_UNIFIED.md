# 平面快照结构、孔隙与有限宽接触特征：统一 Methods

FiberNet 的 `SnapshotFeatureExtractor` 与 FiberScope 特征面板现在调用同一 NumPy 计算核心。输入为 N×2 有限平面坐标、E×2 整数边端点及可选矩形区域；公开图入口还接受 z 坐标恒定的 N×3 图，并投影到 xy 平面。保留独立平行边，不在提取前作简单图去重。矩形分析按**边中点**是否落在区域内筛边，再压缩节点索引；因而它不是裁剪纤维段的几何求交。所有长度与输入坐标同单位，面积是相应平方单位；没有材料标定时使用者须自行声明坐标单位。

结构组包括边数与总长度、长度分布、节点度与熵、取向与各向异性、回转半径、密度、最近邻间距，以及连续二度链的弦长/弧长直线度。交点识别排除共享端点的边对，并以包围盒筛查降低常见输入的开销；在最坏情况下仍为 O(E²)。在交点及边上节点处分割线段，按角度排序的有向半边枚举有界平面面域；孔隙数、面积、周长、长宽比、邻接数量和孔隙率取自这些有界面，不把一般图的环基误作孔隙。孔隙率按区域或节点包围盒面积归一并截至 1，因此它是二维图的几何描述符，并非三维实体体积分数。

有限宽接触为可选分析。给定纤维宽度与 64–1024 的栅格分辨率，每条边按其线段到像素中心的距离生成覆盖；候选非相邻边对先经包围盒筛查，再以公共覆盖像素定义有限宽接触。输出接触对数、参与边比例、重叠像素面积、重叠/纤维覆盖比、四邻域重叠斑块数及接触图最大簇。面积随像素间距与宽度变化，不能直接当作力学接触能或物理粘结面积。交叉角与线段几何重叠另作为不含宽度的描述；两套口径须分别标注。当前 APP 保持原始键与数值语义，迁移前含交点/孔隙/有限宽接触的 54 项金样本完整 JSON 摘要与迁移后严格相等。

公开类默认最多 5000 节点和 800 边，拒绝非整数或越界边、自环、非有限坐标及非平面三维图；最近邻计算分块限制瞬时距离矩阵，接触覆盖像素及候选边对另有独立预算。矩形分析、线段相交和像素化有限宽接触仍可能随输入规模或几何密度显著耗时，建议对大结构先选择区域或降低栅格分辨率。可重跑的纯库示例为 `python -m examples.snapshot_features_workflow --output-dir demo_features --contact`，原子保存标量 JSON 和分布 NPZ。原库旧有 `GraphFeatureExtractor` 使用另一套 94 维定义；不得混合两者的同名指标或把模型训练特征当成本文快照指标。
