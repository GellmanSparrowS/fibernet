# Recorded backend dynamics

See [methods, units and reproduction](data/SAVED_BACKEND_DYNAMICS.md) and [source provenance](data/saved_dynamics_provenance.json).

Run from the repository root: `python docs/media/new/backends/render.py`. Requires NumPy, Pillow and DejaVu Sans fonts at `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf` and `/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf`. No simulation engine is called.

SVG posters are editable compositions; embedded raster elements such as color bars are not individually vector-editable.
