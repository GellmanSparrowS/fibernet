# Import one exact welded crossing

`StructureGraph.from_fiber_network` is the existing approximate endpoint-chord conversion. It does not consume legacy crosslink records; its endpoint proximity merges must not be interpreted as importing internal welds.

For a narrow, opt-in alternative, import `convert_single_welded_crosslink` from `fibernet.core.single_junction_import` and call `graph, report = convert_single_welded_crosslink(network)`. It accepts exactly two nonperiodic, index-uniform straight circular fibers and one welded crosslink at strictly interior points. The parameters are interpolated between successive centerline samples, and coordinates must be exactly representable in float64, and both evaluated points must exactly equal the stored crosslink position. Masked and complex coordinates are rejected, including the box. This check cannot recover a mask or imaginary part already discarded before the function receives the network. Near-but-distinct contacts are rejected, not snapped. Curved or nonuniform centerlines, endpoint junctions, multiple links, other link types, finite link stiffness or strength, Material subclasses, and noncircular section data are unsupported. Two-dimensional centerlines must have zero z. Each fiber is limited to 10,000 samples.

The graph has one shared junction and four straight edges. The report maps source fiber **list indices** and recorded `fiber_id` values to new edge IDs, and records the new junction node ID. Node and edge IDs are newly allocated and are not legacy IDs. Radius, detached material and network metadata are copied; source discretization is not retained: each output edge has four segments. The box must contain two or three finite real coordinates exactly representable in float64; its physical validity is not checked. No inference of units, physical equivalence, boundary conditions or constitutive weld behavior is made. This function does not certify JSON or native-v1 persistence of arbitrary copied metadata or material fields. A crossing that lacks an explicit accepted crosslink is not converted by this function. The default endpoint conversion remains unchanged.
