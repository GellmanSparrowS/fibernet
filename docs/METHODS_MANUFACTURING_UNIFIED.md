# 平面与曲面连续网络编译：Methods 草稿

## 输入、数据对象与计算顺序

输入由基元角点图、二维周期规则、单边无量纲形变谱、随机种子及可选曲面四边形网格组成。平面基元采用边长为 10 个输入坐标单位的参考单元；此值只定义几何比例，不自动解释为毫米。基元角点图首先在参考空间中追踪有向面边界。未被闭合面覆盖的分支添加反向边，保留其独立纤维身份；内部共享侧和外边界也按边出现次数保留或补足独立平行纤维。周期规则对各单元角点施加平移、四分之一转或镜像，坐标在 10⁻⁸ 精度下识别同一参考节点。连接分量时加入往返成对边，随后在参考空间对高阶连接点拆分，使生成的图保持连通和偶度。

形变谱给出参考边上各内部控制点的纵向及法向偏移，均相对于边长无量纲化。指定控制点数后沿边插值；同一随机种子控制可选的谱扰动。圆环基元的内部点保留参考圆弧偏移。编译结果保存参考坐标、实际坐标、有序边数组、边身份及闭合路线。路线由逐边遍历得到，每条独立边在路线中出现一次，起止节点相同；拓扑标识为有序边数组的 SHA-256 摘要。图容器转换时显式保留平行边，避免制造路线的边编号与图中的边数量不一致。

曲面版本先生成单个平面闭合网络，再把参考和实际二维坐标归一化到单元参数域，经双线性四边形映射到各曲面面片。相邻面片只共享规定的角点身份；若共享边仍需显式连接，则在边中点插入往返桥接纤维。输入网格要求有限三维坐标、四个不重复且有效的整数顶点编号，形状放大系数限于 1.00–1.30。超过点/边预算时先对四边形曲面做有界简化；无法满足预算则报错。所有网络均验证连通、偶度和路线覆盖。闭合欧拉路线是拓扑及几何表示的必要检查，但不证明设备路径、喷嘴间距、材料粘结、碰撞、支撑或成品强度满足制造要求。

OBJ 输入在映射前限制文件为 64 MB；未请求面数简化时最多读入 100,000 个顶点和 10,000 个面，请求简化时分别最多为 500,000 和 1,000,000。面顶点索引须为非零、有效且不重复的 3–256 个编号，支持 OBJ 正负索引。非四边形面通过投影三角化和共享边中点构建相容四边形；超过给定目标面数时进行有界三角简化后再转换。输出记录来源顶点数、面数、三角面数、最终四边形数及是否发生简化。曲面坐标需为有限实数；该输入处理不能修复非流形或自相交的来源曲面。

另一种曲面表示在每个四边形面片上分别映射一个完整的单元纤维图，并在共享面边设置显式接缝。先把单元的二维坐标按外包范围映射到参数域，再以双线性插值计算三维位置；共享边的中点作为接缝锚点，在两侧单元纤维上分别找到最近的参数域线段投影，必要时拆分该线段并连接锚点。最后按曲面尺度的 10⁻⁹ 精度合并数值重合点，删除自环并对无向边去重。输入要求有限三维顶点、每面四个不同的整数索引和有限二维形变谱，拒绝浮点索引的隐式截断。默认放大系数为 1.06，允许 1.00–1.30；点数和边数默认上限分别为 150,000 和 200,000，超预算时先对显示用四边形网格有界简化，否则报错。该表示输出连接的段图而非闭合打印路线，与上述连续网络编译是不同的输出语义。公共库和 APP 在同一 108 面 OBJ 的方形、六边形单元上，全部点和边数组完全一致，并与迁移前点/边哈希一致。

## 可复现与适用边界

公共 Python 入口位于 `fibernet.gen`，不依赖 APP 或 Qt。APP 通过兼容导入调用同一计算核心。固定输入下，10 组内置平面结构/周期规则和 3 组曲面结构的有序边、路线与坐标同 APP 对照；平面数组或完全相等，或在 10⁻¹² 坐标容差内一致。APP 全部 25 套回归通过，其中制造专用测试含 252 组平面变形/规则及 12 组曲面拓扑。迁移前后四个引擎黄金案例共 40 个数值数组相对偏差为零。可重跑的独立库示例保存平面与曲面 `.npz`、路线和参数摘要。当前验证属于软件数值一致性，未提供打印工艺或实验力学的外部标定。

## 实体构建与格式输出

输入路径的中心线首先按输出设置缩放为毫米坐标，平面网络按指定宽、深、高放置，曲面网络受最大高度与 250 mm 包络约束。解析实体路径以圆柱段和球形接头构建有限截面的管状网络，空间相近批次用流形布尔并集处理，并在大几何量时提前停止。可选体素路径对中心线采样，以受控体素预算求距离场并提取等值面。实体网格经封闭双流形边计数和非零体积检查；方向为负时统一翻转三角面朝向。STL 以二进制三角面写出，3MF 显式写入毫米单位，CSV 按闭合路线输出逐步节点与入边编号。三种文件先写临时文件，再以原子替换提交，取消和异常时清理临时文件。实体生成依赖可选几何包，库的基础图/路线分析不强制加载这些包。
