# 中文论文工作稿：FiberNet–FiberScope

> 状态：软件方法论文的内部草稿。以下数值均限定在仓库当前模型和测试环境；未进行第三方复现、跨系统验收或材料实验校准，暂不能作为投稿定稿。本文避开已发表 NC 的制造拓扑、FEA–GNN–RL 逆设计和打印性能首创主张。

## 暂定题目

**FiberNet–FiberScope：面向纤维网络构建、数值分析与动态招募研究的可编程—交互式同源平台**

## 摘要（工作稿）

纤维网络的数字化研究同时涉及结构生成、几何约束、力学求解、逐帧分析和结果复核，但同一任务在脚本与图形界面之间的对象、参数和输出容易产生差异。本研究将既有 FiberNet Python 库与 FiberScope 桌面应用的计算核心统一到可安装的库接口，保留交互层作为配置、检查和展示入口。统一后的功能覆盖平面及曲面制造图、独立平行纤维身份、连续闭合路线、平面快照结构/孔隙/有限宽接触描述符、简化拉伸与梁框架模型、动态轴向应变招募、目标曲线搜索及可续跑物理标注数据流。固定数值黄金数据、跨端同参数案例、独立安装 wheel 和剥离开发环境后的冻结应用分别用于核查计算与交付一致性。以拉伸招募作为独立于既有制造优化论文的应用示例，四类网络的加载方向、阈值和几何种子共同构成可复算观察集；独立梁模型保留了一个六边形结构的方向性差异，但未复现简化模型的定量起始位置。完整拓扑家族留出的早期预测基准显示，直接按初期轴向应变排序已具有很高区分度，所测模型未产生稳定增益。同图同夹持的删环复核表明，简化模型认为近乎无损的部分选择在线性梁模型下明显降低反力，揭示该设计判断的模型依赖性。这些结果将平台定位为可检验、可复算的纤维网络研究工具，同时明确区分阈值招募图、完整力流和材料实验性能。

## 引言（工作稿）

胶原纤维网络在加载过程中可出现与应变控制临界性一致的非线性力学响应，模型与实验均显示网络连通状态和形变水平会影响整体刚度。[Sharma 等，Nature Physics，2016](https://www.nature.com/articles/nphys3628) 另一方面，具有空间无序的纤维网络可产生显著的局部刚度异质性，使单个位置的力学观测不能简单代表整个网络。[Beroz 等，Nature Communications，2017](https://www.nature.com/articles/ncomms16096) 对胶原和离体主动脉组织的实验与有限元分析还显示，局部应变异质性的贯通可用于研究组织破裂区域；因此“初期应变包含后期区域信息”并非本研究可以单独主张的新发现。[原始实验研究，Communications Medicine，2025](https://www.nature.com/articles/s43856-025-00897-5)

此前发表的制造约束纤维网络研究已提出连续纤维拓扑、FEA–GNN–RL 逆设计、曲面投影及打印验证，新论文不重复其首次提出和性能提升结论。[Yang 等，Nature Communications，2026](https://www.nature.com/articles/s41467-026-76045-x) 软件方法论文可以将跨数据类型的共同表示、分析接口和可扩展计算作为独立研究对象，Squidpy 的空间组学框架提供了这一写法的实例。[Palla 等，Nature Methods，2022](https://www.nature.com/articles/s41592-021-01358-2) 图形界面与既有科学计算生态的互操作也可构成明确的软件贡献，napari-imagej 将两个影像处理生态在同一交互入口连接。[Selzer 等，Nature Methods，2023](https://www.nature.com/articles/s41592-023-01990-0) 材料计算平台 APEX 则同时报告自动工作流、可视化、代码开放和多个应用案例，提示平台文章需要可执行的任务边界及案例验证。[Li 等，npj Computational Materials，2025](https://www.nature.com/articles/s41524-025-01580-y)

据此，本文提出的可检验贡献是：让同一纤维网络数据对象和科学计算在 Python 与桌面交互之间保持可复核的数值语义，并给出一个涵盖动态招募、方向性、预测基线与受约束干预的独立研究流程。这个主张的范围由实际安装、跨端差异、数值模型比较和失败案例共同限定；界面数量或功能列表本身不作为科学有效性的证据。

## 结果 1：计算对象与跨端同源（工作稿）

统一数据对象保留节点坐标、边端点、半径、材料和独立平行边身份；制造模块在此对象上分别输出参考/实际坐标及边序列，闭合路线另存有序节点和边的遍历。APP 对内置平面单元、曲面四边形映射、OBJ 导入与实体导出的计算调用库模块，交互层负责参数编辑和结果检查。平面快照的结构、孔隙、交点与有限宽像素接触特征也由同一库核心提供，迁移前含 54 键的固定样本与新库/APP 数值完全相同；这些描述符和原有 94 维机器学习特征使用不同定义，不混作一种输入。图对象的连接性与欧拉筛查只是打印路线必要条件，尚未验证打印头避障、成形质量或设备参数。当前库/APP 的同参测试及演示位于 `tests/`、`FiberScope/tests/` 和 `examples/`；后续需将图对象的公共序列化协议与外部用户操作任务纳入正式稿。

## 结果 2：数值与交付一致性（工作稿）

简化拉伸求解器从 APP 移入库后，四个固定黄金案例共 40 组数值数组与迁移前的最大相对偏差为零；旧干预与新观察检查点均在逐案例严格相等后更新至同一源码指纹。自定义单元的图校验、APP 兼容 JSON 持久化和原子写盘也由两端共用；其坐标、边序和闭合路线可由无 APP 的 Python 示例复现。Python 3.10 的库端完整测试目前为 368 项通过、19 项跳过，APP 完整测试为 25 套通过。上一轮本地 wheel 的独立安装实际运行了制造生成、简化拉伸、物理标注及目标曲线搜索；上一轮冻结 APP 在本机 Windows 上完成依赖剥离、端到端冒烟和干净环境目录复制冒烟。两件候选仍需按本轮源码重建复核，不能把旧包验收沿用为新包结论。Methods 细节及命令见 `../docs/METHODS_REDUCED_SOLVER_UNIFIED.md`、`../docs/METHODS_PHYSICAL_DATASET_UNIFIED.md`、`../docs/METHODS_CUSTOM_CELL_UNIFIED.md` 和根目录 `PROGRESS.md`。

## 结果 3：动态阈值招募与方向性（工作稿）

在每个保存帧，边的正向轴向应变与预设阈值比较，并在原图边连接关系上识别与夹持端相连或双端贯通的招募分量。此结果被称为“阈值化拉伸招募网络”，因为模型未以此直接计算弯矩、接触传力或完整局部力流。四类拓扑、三个互异几何种子、两个加载方向和接触开关形成 48 个观察案例；以绝对正向应变下限 0.05 分析时，六边形在所测设置下沿两个方向的首次贯通分别落在第 4 与第 11–12 帧。另一个边上含两个控制点、扰动幅度 0.2 的六边形工作图，在绝对下限 0.10 时沿 x/y 的首次贯通分别为第 8/19 帧；该图单独用于矢量关键帧展示，不混入前述 48 案例统计。三个几何种子的独立非线性梁框架 FEM 在伸长比 1.24 下均给出 x 向贯通、y 向未贯通，但具体起始伸长与简化求解器不同。梁 FEM 快捷入口已修正为保留独立平行边，逐梁力摘要使用真实半径；修正后 18 项边应变贯通判定与旧记录逐项相同，旧力摘要因固定半径换算错误而不能沿用。完整参数及负对照见 `../docs/RECRUITMENT_SENSITIVITY_2026-09-24.md`；这些仍是模型间比较，而非材料实验验证。

## 结果 4：结构干预与提前预测的证据边界（工作稿）

小尺度事后删边实验在同边数与边长类别对照下表明，低招募边删减在部分结构上较高招募边删减更能保留模拟末帧反力，但圆环的一次随机对照略优，六边形几乎不区分策略。逐边方案通常破坏偶度，因而不能直接称为连续纤维制造方案。进一步在四类 3×3 扰动图、三种子和双方向的 24 个加载配置中，对单环删除设置完全相同的移除长度类别，并对每个候选实际构造欧拉回路和重新求解。早期低应变删减在六个方形配置中有四个末帧反力高于固定随机，而在六个笼目配置中没有一个高于固定随机；低轴向对齐度这一静态几何策略也几乎总能保留原图反力。提前识别的独立 24 案例结构族留出基准中，初期正向应变排序的 AP 为 0.974–1.000，随机森林只在一个留出家族略高于该基线。进一步对全部 408 个等长度、保留欧拉路线的单环候选逐一删后重仿真，并以一种完整拓扑家族作为测试集训练早期特征随机森林；模型所选方案的 24 配置平均原始末帧反力比为 0.99999829，静态几何规则为 0.99999824，差异仅约 4.8×10⁻⁸。综合而言，当前数据支持“软件能够提出、执行和反证制造约束干预”的方法主张，尚不支持“AI 已实现更优材料删减”；后续需增加真正独立的几何、载荷、材料与实验对照。数据定义和结果分别见 `../docs/PERCOLATION_MATCHED_2026-09-24.md`、`../docs/CONSTRAINED_CYCLE_INTERVENTION_2026-09-24.md`、`../docs/EARLY_RECRUITMENT_PREDICTION_2026-09-24.md`、`../docs/AI_CYCLE_SELECTOR_2026-09-24.md`。

在相同 24 个加载配置、相同删环选择和相同夹持节点下，将原图与删除图共同拉伸至 1.08，并分别用简化模型及线性梁框架 FEM 重算。简化模型给出的早期低应变方案反力比在四类拓扑均接近 1；梁 FEM 的方形、六边形、圆环和笼目均值分别为 0.988、0.950、0.951 和 0.842，24 配置中有 11 个低于 0.95。两模型绝对材料参数和弯曲假设不同，且删环选择源于简化模型至 1.40 的完整轨迹，因此此处仅是相同小变形终点的跨模型敏感性复核。其结果不支持把简化模型中“低招募边的删除几乎不改变反力”外推为模型无关的力学冗余，更不能称为打印试验；它为平台提供了可检验并能反证设计规则的应用示例。具体几何、夹持、平衡残差和逐案例结果见 `../docs/INDEPENDENT_FEM_CYCLE_INTERVENTION_2026-09-24.md`。

## 讨论与投稿前门槛（工作稿）

目前最充分的证据是计算核心迁移后的跨端一致性、可安装库的实际运行及固定输入下的可复算时序分析。动态招募的方向性为独立科学案例提供了问题和可视化结果，但尚不能外推为力流机制或材料轻量化收益。建议将论文主图集中在“同源计算对象—可复算工作流—方向性招募及反事实干预边界”，把高分但缺增益的分类结果放入方法基线或补充材料。投稿前还需跨机器安装、复杂网络运行成本、独立第三方复现、阈值/材料敏感性和制造约束干预后的实验或可靠独立模型对照；在这些门槛满足之前，摘要与结论不得使用“通用预测”“优化材料性能”或“实验验证力流”等措辞。
